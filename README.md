# Range-Find: The Smarter Find Tool

**Range-Find** is a lightweight browser extension that supercharges the standard "Find" (`Ctrl+F`) functionality. It allows you to not only search for text but also find numbers within a specific range, with powerful filters to include or exclude results based on surrounding characters.

It's the perfect tool for browsing deal websites, financial reports, data tables, or any page with dense numerical information.



---

## Key Features

* **Number Range Search:** Find all numbers on a page that fall between a minimum and maximum value (e.g., find all prices between $50 and $200).
* **Include List:** Only find numbers that are preceded by specific symbols or text (e.g., find numbers that start with `@`, `$`, or `₹`).
* **Ignore List:** Exclude numbers that are next to specific symbols or text (e.g., ignore discount percentages like `78%` or weights like `20g`).
* **Smart Navigation:** Cycle through all found results with "Next" and "Previous" buttons, complete with a counter (`4 / 33`).
* **Auto-Scroll:** The page automatically scrolls to the currently highlighted result.
* **Cross-Browser:** Works on all Chromium-based browsers like Google Chrome, Microsoft Edge, and Brave.

########## Installation (Sideloading in Developer Mode) #############

Since this extension is not yet on the official Web Store, you can easily load it yourself in just a few steps:

1.  **Download the Code:** Click the green **`< > Code`** button on this GitHub page and select **"Download ZIP"**.
2.  **Unzip the File:** Extract the contents of the ZIP file into a folder on your computer. You should have a folder containing files like `manifest.json`, `popup.html`, etc.
3.  **Open Browser Extensions:** Open your browser (Chrome, Edge, Brave) and navigate to the extensions management page. You can usually find this at `chrome://extensions` or `edge://extensions`.
4.  **Enable Developer Mode:** Find the "Developer mode" toggle (usually in the top-right corner) and make sure it's turned **ON**.
5.  **Load the Extension:** Click the **"Load unpacked"** button. A file dialog will open. Select the entire folder you unzipped in Step 2.

The **Range-Find** extension icon will now appear in your browser's toolbar, ready to use!
